# LeadRescue, in plain English

LeadRescue is your app. You do not need to write code to use it.

## What you can try now

The current demo lets you explore the dashboard and enter sample business details. It does not call or message anyone. Real customer accounts and messaging need additional setup in later steps.

## How you will use it

1. **Open one website link.** The app must first be published to a secure website. There is no public app link yet; it currently runs inside the development workspace.
2. **Choose “Explore the demo.”** No phone-number purchase or payment is needed to explore it.
3. **Choose “Get the app.”** Follow the Android or computer instructions. Where supported, the browser will offer “Install LeadRescue.”

On Android, use Chrome's three-dot menu → Add to Home screen → Install (or “Install app”). On a laptop or desktop, use Chrome or Microsoft Edge's install button. The app gets an icon and opens in its own window. It still needs internet access. Browser support and menu labels vary.

This is a browser-installed app, not an APK or Windows installer. App-store publication and iOS-specific work are not part of the current change.

## The next step: a public demo link

The website needs a hosting account. Vercel is the intended host for this project. Preparing or publishing a Codex cloud environment saves the development workspace; it does **not** publish a public website.

Before deployment, the source must be pushed to your GitHub repository and that repository connected to Vercel. Hosting account setup and any plan selection stay under your control. Do not buy Twilio numbers or activate paid messaging to try the demo.

The developer-facing deployment instructions are in README.md. After publication, the app's public address becomes the link you use and install from. A paid custom domain is not required to test; a hosting-provider address can be used if available under your selected plan.

Once you are comfortable with the demo, continue building the CRM, simulator, and real messaging phases. Installing the app does not make unfinished features available.
